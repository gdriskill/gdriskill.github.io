Ecoli Pathotype Prediction

Blah blah blah

This project was a group final project for the Machine Learning in Computational Biology course (CSE 7850) at Georgia Tech in Spring 2024. We tested several machine learning models against whole-genome shotgun short-read sequences to identify the most effective ML approach in predicting E. coli pathotypes.

Using a dataset of approximately 22,000 sequenced E. coli isolates, we identified pathotype-specific virulence genes using the BLAST algorithm, revealing six unique pathotypes and 427 unique virulence factors We selected ML classification models with diverse approaches: Decision Tree (DT), Gradient Boosting (GB), K-nearest Neighbor (KNN), Logistic Regression (LR), Multi-layer Perceptron (MLP), Random Forest (RF), and Support Vector Classification (SVC). We then trained those models on the raw data using a 70/30 split for training and validation to get baseline performance metrics (accuracy, precision, recall, F1-score) for each model.

Next, we applied two feature engineering techniques, Multiple Correspondence Analysis (MCA) and Recursive Feature Elimination with Cross-Validation (RFECV), to improve performance. Following feature engineering, we performed hyperparameter tuning and retrained the models using the same split. Finally, we evaluated the models on an unseen dataset of E. coli genomes.

My personal contributions to the project include writing the code for training and evaluating the models, and feature selection using RFECV. I also wrote the section in the report about the feature selection, and contributed to editing our final report.
