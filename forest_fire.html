Forest Fire Burn Area Prediction

blah blah blah

This project is an individual final project for the Computational Data Analysis course (CSE 6740) at Georgia Tech in Fall 2023. The primary objective of the project was to create a regression model capable of estimating the burn area for a specific location on a given day given geographic, temporal and meteorological data. Such predictions have the potential to be useful for forest fire management, aiding in assessing potential fire severity and optimizing the allocation of resources.

The dataset used for this project is originally from Cortez and Morais 2007, which is available in the UCI Machine Learning Repository. I developed three different regression models: linear regression, support vector regression (SVR), and artificial neural network (ANN). The linear regression and SVM models were implemented using Scikit-learn, while the ANN model was built using PyTorch.

To evaluate the performance of these models, I compared them using mean squared error (MSE) as the metric for prediction accuracy, and the generalization gap, which is the difference between training and test errors, to determine how well the models could generalize to unseen data. The results revealed that the linear regression model achieved the best test error, indicating its high predictive accuracy on new data. On the other hand, the SVR model demonstrated the best generalization capability with the smallest generalization gap. The ANN showed signs of overfitting; the model had the largest difference between test and training error, along with the lowest training error.
