Connect 4

blah blah blah

This project is an individual final project for the Human-Computer Interaction course (CSC 343) at University of Arizona in Spring 2022. The objective of this project was to create a multiplayer Connect 4 game while focusing on usability and user experience. I went through an iterative development process that is documented in detail in the project report.

To specify the requirements for this project, I listed the usability and user experience goals, detailed the who/what/where/when/why of this application, and created user personas and use cases. While designing the game, I created multiple potential layouts informed by UX theories from class and wrote a storyboard visualizing the user interactions. After initially implementing the game, I had family and friends test it out. In addition to observing their usage, I also survey them afterwards about their experience. With their feedback and my observations, I was able to tweak a few details to create a better version of the game.
